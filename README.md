# Modrinth Auto Filter - Chrome Ext
このリポジトリは、[Modrinth](https://modrinth.com)において、事前にModのバージョンやプラットフォームを指定することで、  
ユーザがModのVersionsページを開くだけで自動的に指定したものに修正するChrome拡張機能です。  
ソースコードを直接ダウンロードして導入するか、[Chromeウェブストア](https://chromewebstore.google.com/detail/modrinth-auto-filter/keikbbacpkoamogknjhbkeihbjkbobgd)からインストールが可能です。  
バグなどを発見した場合、[Issues](https://github.com/Rin-ot/Modrinth-Auto-Filter/issues)よりご報告ください。
